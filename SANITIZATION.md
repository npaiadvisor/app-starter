# Sanitization rule

This repository is **public**. Never commit client-identifying data, credentials, or organization-internal infrastructure — in code, docs, examples, fixtures, or commit messages. Use generic invented examples and placeholders (`your-api-key`, `YOUR_ORG.org`). Keep real secrets only in a git-ignored `.env.local`. See the [commons sanitization rule](https://github.com/npaiadvisor/discovery/blob/main/SANITIZATION.md) for the full checklist.
